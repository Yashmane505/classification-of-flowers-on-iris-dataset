Algorithm Documentation

Our Iris Classification AI uses Logistic Regression as its primary classification engine, supported by Linear Regression for comparative analysis.

What is Logistic Regression?

Despite the name "regression," Logistic Regression is used for Classification. It estimates the probability of a given input belonging to a specific category (Setosa, Versicolor, or Virginica).

P(y=1|X) = σ(W · X + b) = 1 / (1 + e^-(W · X + b))

Where σ is the Sigmoid Function, which maps any real value into the range (0, 1), representing a probability.

How it works on Iris

1. Feature Input

We take 4 features: Sepal Length, Sepal Width, Petal Length, and Petal Width.

2. Probability Map

The model calculates weights for each feature to determine how much it influences the species type.

3. Decision Boundary

A threshold is applied. For multi-class (Iris), we use "One-vs-Rest" or Softmax to pick the highest score.

Comparative Analysis

In this app, we compare Two approaches:

  • Logistic Regression: Predicts discrete categories. More accurate for this dataset.
  • Linear Regression: Predicts continuous values (0 to 2), which we then round to the nearest flower index.

Data Source: Fisher's Iris Dataset (1936), a classic in machine learning education.
